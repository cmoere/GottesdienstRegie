# v97 implementation plan

> Root uses superpowers:executing-plans inline. Only translation work may be delegated; implementation and review remain native.

**Goal:** Measured live delivery, reliable startup, explicit audio diagnostics and real local AI-generated editable slides.
**Architecture:** Extend existing output revisions, startup ordering, audio taps and slide store. Pin/download a small ONNX text model and execute inference separately from operator/output rendering.
**Tech stack:** Existing React/TypeScript/Electron, Transformers.js 3.8.1, Vitest and native Electron smoke fixtures.
**Spec:** docs/superpowers/specs/2026-11-02-v97-design.md

## Constraints and review focus

- Source content stays local; initial in-app model download, no external application or API account; no inference at startup or ON AIR.
- Preserve selected versus live, output routing, recovery/document ordering, existing visitor designs and all31 regional coverage.
- Reject stale/foreign output acknowledgements and generated malformed/oversized content; never execute model output.
- Download/inference cancellation, ON AIR entered during drafting, missing model files, low resources and renderer restart must leave MAIN and saved document unchanged.
- Native app-render timing is not physical screen/speaker verification. Keep the foreign untracked startup diagnostic untouched.
