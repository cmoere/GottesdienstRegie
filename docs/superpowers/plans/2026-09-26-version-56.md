# Version 0.56 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repair the audio browser and add the requested Bible, radio, add-menu, quick-action, preview-timer, terms, and release improvements as version 0.56.0.

**Architecture:** Keep the Cloudflare Worker immutable and add a typed client for its public GET API with the existing GetBible provider as fallback. Isolate availability and countdown calculations in small tested helpers, while existing React surfaces render the resulting state.

**Tech Stack:** React, TypeScript, Zustand, Electron, Vitest, CSS, GitHub Actions.

**Spec:** Confirmed design in the current chat on 26 September 2026.

- Old/New Testament grouping must remain searchable.

- “Ohne Text” must never execute when no hideable elements exist.
- Timer progress must stay bounded for zero, elapsed, and overlong values.
