# v88 Visitor Display Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. The user selected native execution; delegation is authorized only for translation work. Steps use checkbox syntax for tracking.

**Goal:** Implement the approved v88 visitor-display changes without disturbing current live output, audio or installed software.

**Architecture:** Retain Electron's central services, validated IPC and prepared output snapshots. Guard asynchronous radio replies by session and track identity. Extend the existing output composition for region-filtered DWD notices and reuse its absolute presentation time in the live mirror.

**Tech Stack:** Existing TypeScript, React, Electron, Zustand, Vitest, Playwright/native Electron checks, saxes/JSZip where needed; no new dependency without demonstrated need.

**Spec:** `docs/superpowers/specs/2026-10-23-v88-design.md` (user approved 23.10.2026).

## Global Constraints

- Native implementation in existing named worktree; preserve `tests/smoke/startup-diagnostic.cjs` and all unrelated work. No installer execution, physical output activation or release upload.
- DWD notices only PRE, POST or an active countdown; never automatically interrupt service content. Black, emergency Quick Screens, screen test and OFF AIR take priority.
- Only Westfalen-Blatt news, including migration of stored WDR selections and exclusion of old WDR cache rows. Existing source attribution remains.
- Test watermark remains above content in test mode. Preview video is silent; radio/audio routing is unchanged.
- Minimum screen-test duration: five stable seconds per each of eight patterns, bounded by twenty seconds per pattern. Reports HTML/JSON; no claim of physical projector/cable verification.
- Weather: configured location, next twelve hours at two-hour intervals and separate tomorrow forecast. Europe/Berlin and DST must be handled with actual instants.
- Announcement standard follows screenshot, Cera Pro, #699f3e, white background, full-width black separator, QR bottom-right; retain rich text and QR controls. Existing other designs remain selectable.
- No automatic widening of localization approvals or claim that experimental PowerPoint mode is ready. Publish only on a subsequent explicit release request.

## Review Focus

1. Stopped/restarted same station and delayed artwork from a former track must not resurrect old metadata (Task 1).
2. Out-of-order IPC completions, late-mounted mirrors and active transitions must not rewind output or double-delay a take (Task 2).
3. Stored WDR-only requests and mixed caches must never leak a WDR row or initiate a WDR request (Task 3).
4. Warning expiry, overlapping alert/banner content, unknown region and network failure must not present a stale all-clear or cover emergency actions (Task 6).
5. Untrusted report text, DST repeated hours and extremely long announcement titles must remain safe, ordered and fully readable (Tasks 4, 5, 7).
