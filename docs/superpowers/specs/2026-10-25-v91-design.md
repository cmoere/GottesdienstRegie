## Decisions and boundaries
- First banner snapshot is immediately eligible when data arrives; replacing an already-visible ticker remains cycle-bound. Existing content/media/audio priorities and public data filtering stay. Warm DWD warnings before ON AIR; cached valid results display at the first eligible output. No invented warnings or hiding connection status. Confirmation is required before disabling warnings; cancellation preserves enabled state and current output. The persisted option defaults enabled.
- Enlarge native current weather most, retain forecast/tomorrow, source text, actual WMO condition animations and reduced-motion support. Use existing brand colors, restrained condition-specific motion.
- External advertising is an explicit media-browser source with local files/direct media URLs and provider adapters. Do not present public-interest messages as commercial ad inventory or promise an unavailable account-free commercial network. Credentials, if required by a selected provider, are explicit operator configuration. Advertising remains restricted to authorized PRE/POST scheduling.
- New speech uses two genuinely different locally bundled neural German voices with pinned models/runtime and model-specific redistribution notices. Reuse device-level shared selection, single announcement owner, configured audio route, gong, cancel, ducking and peak protection. No audio engine bypass or system voice. Evaluate maintained Piper/runtime packaging and run actual synthesis on each platform before shipping.
- Imports must read real .one/.onepkg and .key data. Use bounded local parsers/converters, preserve all discovered pages and ordered content, and return an honest import report for unsupported layout/animation. Do not call a single Keynote cover image a complete deck import. No cloud uploads or executing document macros. A platform-native Keynote export may supplement the cross-platform parser where available.
- Personal Monitor: improve current/next/clock/countdown/readability and actual slide display. QR code alongside copy/open. Read-only monitor URLs remain read-only. Live drawing requires an explicitly paired role with a separate annotation permission; marks propagate as validated normalized strokes to all actual output layers and operator preview, never as slide edits. Clear on new live take, revocation and operator clear; emergency/black keeps operator priority. No bearer token in MAIN payload, strict payload/rate limits.
- Use normal sentence/title capitalization in new and touched controls; preserve established role names MAIN/ON AIR and public source text verbatim.
