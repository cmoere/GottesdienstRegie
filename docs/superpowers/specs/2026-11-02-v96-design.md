# v96 — Vorschauen, Informationen und Bildschirmfreigabe

User scope: v96 request and subsequent clarification. The presenting device shares to MAIN. User chose fluid local HTTPS sharing over periodic screenshots and then instructed implementation/publication.

Build on existing React/Electron, RemoteServer, output composition and live-state controllers. No second event database. Visitor content stays unchanged except the explicitly requested banner punctuation, QR position and weather visual effect. Regional UI remains complete; new operator copy needs authored entries in all31 packs before release. Only translation authoring may be delegated.

## Chosen design

- Stable bundled voice IDs, with explicit gender metadata and `(M)` / `(W)` in the voice selector.
- German regional selector only when language is German. The main language field also displays the selected region.
- Genuine current/next rendered thumbnails, correct aspect ratio and selection/live separation in overview. Small accessible popup contains overview size/title/next-preview preferences; settings persist locally.
- News default: one story for each actual live visit, next story on the next visit. Alternative: rotate every configured X seconds. Renderer stays pure; React redraw, SELECTED changes and preview renders never consume a story. Adopt data at safe takes.
- Song-translation mode has a small adjacent preview using the same song layout renderer and selected mode.
- All announcement designs anchor the fixed QR bottom-right, outside the mandatory test watermark; body viewport avoids overlap and retains rich-text scrolling. Banner fallback title plus description uses `Title: Description`; explicit authored banner text remains authoritative.
- Quiet weather-dependent output effects, with deterministic motion phase and reduced-motion handling. Preserve readability and current data.
- Speech-only German corrections: conservative, unambiguous normalization with operator-visible review; never rewrite stored records, proper names, Bible/song text or visitor content.
- Drawing tools: pen, line, arrow, rectangle, ellipse; validate bounded normalized coordinates and permissions centrally, render vector geometry consistently on MAIN/STAGE/preview, clear on take/quick-screen boundaries.
- Sharing: local HTTPS + WebRTC. Alternative considered: periodic screenshots (simpler but motion is inferior); user selected WebRTC. The connected browser explicitly selects a source. Regie receives a preview and takes it to existing ON-AIR MAIN. Stop/disconnect/OFF AIR closes tracks/peers and restores ordinary output; emergency quick screens and test watermark stay above shared video. No root certificate is silently installed, no public relay/account is required, device explicitly trusts local HTTPS. Unsupported browsers get a clear capability message.
- Improve device pairing and personal-monitor UI with grouped controls, actual next-slide images, connection status, QR/link access and full-screen controls. Pure monitor links remain read-only.

## Verification focus

Actual next slide includes rich/media content rather than body text alone. Cursor advances exactly once per take and not on data refresh. QR never overlaps long body or test watermark at any allowed size. Language changes preserve routing/live/media. Revoked/view-only sessions cannot draw or share. Late signals from previous shares cannot replace current MAIN. Browser stop/disconnect and emergency actions leave no ghost video/audio. Public output never contains technical errors.
