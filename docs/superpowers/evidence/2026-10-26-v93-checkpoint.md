### Immutable originals

`PowerPointSourceStore` stores validated, SHA-256 addressed original PPTX bytes separately from editable text copies. Imports carry a source hash. Export, backup and reimport carry a bounded portable source envelope, validated before use. References survive reopening; modified/missing sources are rejected. Old copies lacking original bytes cannot be reconstructed and need explicit reassociation.

`work/v93-powerpoint-portable-green.log`: 17 tests in 3 files, including recovery. Latest focused rerun `work/v93-checkpoint-unit.log`: 16 tests in 5 files. Portable-envelope bounds now include a real 33-entry rejection, not just a test title claiming it.
