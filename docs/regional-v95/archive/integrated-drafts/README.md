# Integrated regional documentation drafts

These 32 files are the unchanged help/release drafts that supplied the 16 formerly missing documentation packages. They were integrated into the 31 runtime packages before v95's current interface guide and release notes were authored. Their SHA256 values and former paths are recorded in `manifest.json`.

They are historical authoring evidence, not current runtime translations. Keeping them in the active draft directory would compare their old article source with the revised v95 guide and incorrectly imply that they were still awaiting integration. Runtime coverage remains mandatory for all 31 packages under `src/regional/docs`; the strict checker is unchanged and still validates every current help and release field there. The old drafts remain recoverable here and in commit `d23d62d`.
