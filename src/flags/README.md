# Lokale Sprachsymbole

Die vereinfachten Flaggen-SVGs wurden für GottesdienstRegie anhand der gemeinfreien geometrischen Nationalflaggen neu erstellt. Für Sprachen ohne eindeutige Länderzuordnung wird bewusst ein neutrales, selbst erstelltes Globus-Symbol verwendet. Es werden keine Emojis und keine extern geladenen Bilddateien benutzt.
